# MI-Self-Driving-Hydrogel: AA-DMAEA Polyelectrolyte 🧪🤖

Welcome to my active research log! This repository tracks my journey in integrating Machine Learning with wet-lab materials synthesis, specifically focusing on poly(acrylic acid)-based (AA-DMAEA) polyelectrolyte hydrogels via ball milling.

## 🎯 Project Objective
To accelerate the discovery of the critical formulation (water content, milling time, monomer ratio) for optimal stretchability and ionic conductivity using **Bayesian Optimization** and **Active Learning**, moving towards a closed-loop "Self-Driving Lab" paradigm.

## 📂 Repository Structure
* **`/Literature_Notes`**: My digested insights from key Materials Informatics (MI) papers.
* **`/Data_Processing`**: Python scripts (assisted by Codex) for automating the analysis of raw XRD, TGA, and rheology data.
* **`/Bayesian_Optimization`**: The algorithmic core. Initial scripts for Gaussian Process Regression to guide the next set of wet-lab experiments.

## 🚀 Current Progress (Continuously Updated)
* [x] Established the baseline formulation for anhydrous ball milling.
* [x] Observed gradient water absorption properties (potential for epidermal electronics).
* [ ] (WIP) Building the initial Gaussian Process model based on 20 preliminary experimental data points.
